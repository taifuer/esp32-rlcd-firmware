# 界面与按键

固件把屏幕内容分为“日常功能”和“系统中心”两条路径。日常页面只保留高频信息；版本、
诊断和维护操作集中到系统中心，避免两个实体键在不同页面承担难以预测的含义。完整设计
原则见[产品界面与交互设计规范](design-guidelines.md)。

```text
日常功能（BOOT）
  首屏 <-> 月历

系统中心（KEY）
  设备健康 -> 网络与时间 -> 音频 -> Wi-Fi 维护 -> 在线更新 -> 本地更新 -> 循环
```

## 实体按键

| 按键 | 日常页面 | 系统中心 |
| --- | --- | --- |
| 短按 `BOOT` | 首屏与月历互相切换 | 返回首屏 |
| 短按 `KEY` | 进入“设备健康” | 切换到下一系统页 |
| 长按 `BOOT` | 无运行时操作 | 无运行时操作 |
| 长按 `KEY` | 无操作 | 仅执行当前页面明确提示的操作 |
| `PWR` | 短按开机，长按关机 | 同左 |

月历和所有系统页无操作 30 秒后返回首屏。长按中的按键、音频测试、校时任务、Wi-Fi
重置倒计时和固件更新会暂停超时。音频录制或回放时，屏幕明确显示的 `KEY: STOP` 与
`BOOT: CANCEL` 临时取代页面导航；在线更新检查、连接和确认阶段也可按 `BOOT` 取消。
操作结束后恢复表格中的普通语义。

关机后“按住 `BOOT`，再短按 `PWR`”仍用于进入 ESP32-S3 ROM 下载模式。此时应用固件
没有运行，屏幕不会绘制烧录进度；它与正常运行时的 `BOOT` 页面切换是两种不同场景。
正常运行时通过在线更新或本地更新写入固件时，应用仍在运行，因此屏幕可以显示真实进度。

## 首屏

![首屏效果图](assets/home-screen.svg)

400 × 300 首屏采用黑底白字三段式布局：

- 顶部显示公历日期、无“农历”前缀的农历月日、星期，以及 Wi-Fi 与电池状态组；四组
  按实际宽度分配相等间距，状态组使用固定占位，避免内容跳动；
- 中部以同一种 78 像素数字字体等大显示 `HH:MM:SS`，字形视觉中心位于整屏中央；
- 底部只显示温度、心形分隔和湿度。温湿度使用 20 像素字体，分别以左右半屏为中心；
- 固件版本、传感器诊断、原始电压和网络错误码不进入首屏。

完整 Wi-Fi 图标表示本次启动已成功完成网络校时，不表示无线射频持续开启；下半层图标
表示正在连接或校时，带斜杠表示未配置、Wi-Fi 离线或 NTP 暂不可用。自动联网只改变这个
结果图标，不会覆盖首屏或打断本地功能。蓝牙尚未启用，因此不显示蓝牙图标。

农历在设备上离线换算，覆盖 2000—2099 年并支持闰月。温湿度来自板载 SHTC3，代表设备
附近环境，不是联网天气。电池百分比由 GPIO4 采样电压估算，受充电、负载和电芯老化
影响，仅作为近似值。

## 月历

![月历页效果图](assets/calendar-screen.svg)

月历显示 RTC 当前月份，以星期一为每周首日，并用实心圆反色突出今天。顶部显示当月、
当天农历、星期和当前时分。当前版本不提供历史月份翻阅，避免两个按键承担额外模式。

## 系统中心

六个系统页共用标题、`1/6`—`6/6` 位置、内容网格和底部按键提示，但每页只负责一类
问题：

| 页面 | 内容 | 当前页长按操作 |
| --- | --- | --- |
| 设备健康 | RTC、RTC 备用电池保持结果、SHTC3、电池和 PSRAM | 无 |
| 网络与时间 | 网络状态、RTC、最近校时和 24 小时正常周期 | 按住 `KEY` 2 秒立即校时 |
| 音频 | ES8311 扬声器、ES7210 双麦克风状态和最近测试结果 | 按住 `KEY` 2 秒执行临时回放测试 |
| Wi-Fi 维护 | 是否已保存网络配置及重配网影响 | 按住 `KEY` 5 秒清除配置并重启 |
| 在线更新 | 当前版本、对应通道最新版本和最近检查结果 | 按住 `KEY` 2 秒检查或查看可用版本；确认页按住 3 秒安装 |
| 本地更新 | 当前固件、ESP-IDF、本地网页入口和 USB 恢复说明 | 按住 `KEY` 3 秒开启更新热点 |

| 设备健康 | 网络与时间 |
| :---: | :---: |
| ![设备健康页效果图](assets/device-health.svg) | ![网络与时间页效果图](assets/network-time.svg) |
| 音频诊断 | Wi-Fi 维护 |
| ![音频诊断页效果图](assets/audio.svg) | ![Wi-Fi 维护页效果图](assets/wifi-maintenance.svg) |
| 在线更新 | 本地更新 |
| ![在线更新页效果图](assets/online-update.svg) | ![本地更新页效果图](assets/local-update.svg) |

“网络与时间”发起校时后会显示启动 Wi-Fi、连接和等待 NTP；写入并回读 RTC 成功后显示
结果，再返回该页面。后台正处于离线退避时也可立即重试；未保存 Wi-Fi 或网络任务忙碌时
只提示不可用，不修改配置。

“设备健康”的 `RTC BACKUP` 不显示电压：开发板没有把 RTC 电池接入 ESP32 ADC。首次运行
显示 `UNTESTED`；固件保存一次 RTC 时间标记，下一次真实断电开机时在联网前检查 PCF85063
停振标志和时间变化，通过后显示 `VERIFIED`，曾丢失有效时间则显示 `FAILED`。该结果只
证明最近一次断电保持成功，不估算电池容量或剩余寿命。

“音频”页首先显示扬声器、双麦克风和 `24 kHz / 16-bit` 格式是否就绪。按住 `KEY`
2 秒后，设备先播放两声短音，再临时采集最多 5 秒语音，同时显示两路物理麦克风的相对
活动强度；短按 `KEY` 可提前结束录制。随后固件选择信号更强的一路，去除直流、限制增益
并淡入淡出后自动回放；回放中仍可短按 `KEY` 停止，整个过程可短按 `BOOT` 取消。

`TONE PLAYED` 和 `VOICE PLAYED` 都只表示数据已写入扬声器链路，是否真正听到需由用户
确认。原始语音只临时存在 PSRAM，播放、取消或失败后立即覆写并释放，不写入 Flash、
NVS、SD 卡、USB 日志或网络；页面只保留录制时长、两路强度与流程结果。

“Wi-Fi 维护”从按住 `KEY` 1 秒开始显示剩余时间，满 5 秒才清除本项目的网络凭据并重启
配网；提前松开立即取消。

“在线更新”显示 `NOT CHECKED`、`CHECKING`、`UP TO DATE`、`UPDATE AVAILABLE` 或
`FAILED`。按住 `KEY` 2 秒检查；已有可用版本时，同样按住 2 秒进入 `REVIEW` 确认页，核对
目标版本后再按住 `KEY` 3 秒才开始安装。自动联网只检查，不会弹出页面或静默安装。检查、
连接和确认阶段可按 `BOOT` 取消；开始下载并写入 Flash 后按键不得中断。

“本地更新”从按住 `KEY` 1 秒开始提示，满 3 秒开启随机密码保护的临时更新热点；等待
上传时可短按 `BOOT` 取消，接收固件后按键不会中断写入。本地更新不依赖互联网，始终作为
离线维护入口。完整步骤见[固件安装与更新](firmware-update.md)。其他页面长按 `KEY`、以及
任何页面长按 `BOOT` 都不会执行隐藏动作，松开也不会被误判为短按。

## 异常状态

- RTC 无效时首屏使用 `--:--:--` 和日期占位符，温湿度、电量、系统中心和音频功能仍可
  使用；自动连接、NTP 失败和后台重试不显示全屏错误；
- 仅首次配置或用户主动清除网络配置后显示配网二维码；显示 60 秒后恢复首屏，临时热点
  最多继续开放 5 分钟，也可按屏幕提示的 `BOOT: OFFLINE` 立即回到首屏；
- 温湿度不可用时在原位置显示 `--`；电池不可用时保留空图标并显示 `--%`；
- 系统页使用 `NOT FOUND`、`READ ERROR`、`NOT CONFIGURED` 等短状态，详细错误码只写入
  USB 日志。

## 数据与设计参考

- 农历月界以[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)
  为校验依据；
- 电池采样电路与实体按键依据[微雪 ESP32-S3-RLCD-4.2 文档](https://docs.waveshare.net/ESP32-S3-RLCD-4.2/)；
- 页面层级、浅导航和实体按键语义参考 Apple 与 Garmin 的官方指南，具体链接集中在
  [设计规范](design-guidelines.md#参考原则)。
