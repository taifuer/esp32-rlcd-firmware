# 界面与按键

固件把屏幕内容分为“日常功能”和“系统中心”两条路径。日常页面只保留高频信息；版本、
诊断和维护操作集中到系统中心，避免两个实体键在不同页面承担难以预测的含义。完整设计
原则见[产品界面与交互设计规范](design-guidelines.md)。

```text
日常功能（BOOT）
  首屏 <-> 月历 [<-> 图片（仅有效图片时）]

系统中心（KEY）
  状态 -> 音频 -> 设置 -> 在线更新 -> 循环
```

v0.12.0 只在开机时从 microSD 成功读到有效图片后加入图片页；无卡或没有
有效图片时，日常页面环仍为“首屏 → 月历 → 首屏”。

## 实体按键

| 按键 | 日常页面 | 系统中心 |
| --- | --- | --- |
| 短按 `BOOT` | 切换到下一日常页；有效图片时条件加入图片页 | 返回首屏 |
| 短按 `KEY` | 进入“状态” | 切换到下一系统页 |
| 长按 `BOOT` | 无运行时操作 | 无运行时操作 |
| 长按 `KEY` | 无操作 | 仅执行当前页面明确提示的操作 |
| `PWR` | 短按开机，长按关机 | 同左 |

月历、图片和所有系统页无操作 30 秒后返回首屏。长按中的按键、音频测试、校时任务、
设置门户
和固件更新会暂停超时。音频录制或回放时，屏幕明确显示的 `KEY: STOP` 与
`BOOT: CANCEL` 临时取代页面导航；在线更新检查、连接和确认阶段也可按 `BOOT` 取消。
操作结束后恢复表格中的普通语义。

关机后“按住 `BOOT`，再短按 `PWR`”仍用于进入 ESP32-S3 ROM 下载模式。此时应用固件
没有运行，屏幕不会绘制烧录进度；它与正常运行时的 `BOOT` 页面切换是两种不同场景。
正常运行时通过在线更新或设置门户写入固件时，应用仍在运行，因此屏幕可以显示真实进度。

## 首屏

![首屏效果图](assets/home-screen.svg)

400 × 300 首屏采用黑底白字三段式布局：

- 顶部显示公历日期、无“农历”前缀的农历月日、星期，以及 Wi-Fi 与电池状态组；四组
  按实际宽度分配相等间距，状态组使用固定占位，避免内容跳动；
- `NORMAL` 模式在中部以同一种 78 像素数字字体等大显示 `HH:MM:SS`；`SAVING` 模式显示
  `HH:MM` 并按分钟刷新，两种布局的字形视觉中心都位于整屏中央；
- 底部只显示温度、心形分隔和湿度。温湿度使用 20 像素字体，分别以左右半屏为中心；温度
  单位可在设置门户选择摄氏度或华氏度；
- 固件版本、传感器诊断、原始电压和网络错误码不进入首屏。

完整 Wi-Fi 图标表示本次启动已成功完成网络校时，不表示无线射频持续开启；下半层图标
表示正在连接或校时，带斜杠表示未配置、Wi-Fi 离线或 NTP 暂不可用。自动联网只改变这个
结果图标，不会覆盖首屏或打断本地功能。`SAVING` 不自动联网，手动校时和升级仍可按需
开启 Wi-Fi。蓝牙尚未启用，因此不显示蓝牙图标。

农历在设备上离线换算，覆盖 2000—2099 年并支持闰月。温湿度来自板载 SHTC3，代表设备
附近环境，不是联网天气。电池百分比由 GPIO4 采样电压估算，受充电、负载和电芯老化
影响，仅作为近似值。

## 月历

![月历页效果图](assets/calendar-screen.svg)

月历显示 RTC 当前月份，以星期一为每周首日，并用实心圆反色突出今天。顶部显示当月、
当天农历、星期和当前时分。当前版本不提供历史月份翻阅，避免两个按键承担额外模式。

## microSD 图片

![microSD 图片页效果图](assets/image-screen.svg)

图片页是可选的第三个日常页面。固件开机时使用 ESP-IDF 原生 1-bit SDMMC
以应用层只读方式读取 FAT32 microSD，固定目录 `/rlcd/images/` 中最多允许 32 个 ASCII
文件名候选。文件按不区分大小写的 ASCII 顺序排列，无法解码的文件被跳过，
页面显示排序后第一张
有效图片。不在屏幕上显示文件名、路径、容量或诊断码。

首选格式是二进制 PBM P4，另外只接受尺寸、位深、压缩和调色板都符合限定的 1-bit
BMP 子集。两种格式都必须是 400 × 300 纯黑白像素。底部 50 像素由固件保留并
重画为 `BOOT: PAGE | KEY: SYSTEM`，因此主要图像内容应放在顶部 400 × 250 区域。

该功能不轮播、不在设备端缩放或抖动、不修改文件，也不使用 microSD 保存音频或运行
数据。必须物理关机后再插卡、拔卡或换卡；运行中插入的卡需要重新开机才会识别。完整
准备方法和故障排查见 [microSD 图片准备](microsd-images.md)。

## 系统中心

四个系统页共用标题、`1/4`—`4/4` 位置、内容网格和底部按键提示，每页只负责一类问题：

| 页面 | 内容 | 当前页长按操作 |
| --- | --- | --- |
| 状态 | RTC、RTC 备用电池、SHTC3、电池和网络校时摘要 | 按住 `KEY` 2 秒立即校时 |
| 音频 | ES8311 扬声器、ES7210 双麦克风状态和最近测试结果 | 按住 `KEY` 2 秒执行临时回放测试 |
| 设置 | 省电模式、时区、温度单位、播放音量和本地设置门户 | 按住 `KEY` 3 秒开启设置门户 |
| 在线更新 | 当前版本、对应通道最新版本和最近检查结果 | 按住 `KEY` 2 秒检查或查看可用版本；确认页按住 3 秒安装 |

| 状态 | 音频 |
| :---: | :---: |
| ![状态页效果图](assets/status.svg) | ![音频页效果图](assets/audio.svg) |
| 设置 | 在线更新 |
| ![设置页效果图](assets/settings.svg) | ![在线更新页效果图](assets/online-update.svg) |

“状态”页发起校时后会显示启动 Wi-Fi、连接和等待 NTP；写入并回读 RTC 成功后显示结果，
再返回该页。即使 `NORMAL` 正在离线退避，或 `SAVING` 已关闭自动联网，手动操作也可立即
重试；未保存 Wi-Fi 或网络任务忙碌时只提示不可用，不修改配置。

`RTC BACKUP` 不显示电压：开发板没有把 RTC 电池接入 ESP32 ADC。首次运行显示
`UNTESTED`；固件保存一次 RTC 时间标记，下一次真实断电开机时在联网前检查 PCF85063
停振标志和时间变化，通过后显示 `VERIFIED`，曾丢失有效时间则显示 `FAILED`。该结果只
证明最近一次断电保持成功，不估算电池容量或剩余寿命。

“音频”页首先显示扬声器、双麦克风和 `24 kHz / 16-bit` 格式是否就绪。按住 `KEY`
2 秒后，设备先播放两声短音，再临时采集最多 5 秒语音，同时显示两路物理麦克风的相对
活动强度；短按 `KEY` 可提前结束录制。随后固件选择信号更强的一路，去除直流、限制增益
并淡入淡出后自动回放；回放中仍可短按 `KEY` 停止，整个过程可短按 `BOOT` 取消。

`TONE PLAYED` 和 `VOICE PLAYED` 都只表示数据已写入扬声器链路，是否真正听到需由用户
确认。原始语音只临时存在 PSRAM，播放、取消或失败后立即覆写并释放，不写入 Flash、
NVS、SD 卡、USB 日志或网络；页面只保留录制时长、两路强度与流程结果。

“设置”页显示当前电源模式、时区、温度单位和回放音量，并以
`PORTAL  CONFIG | RTC | WI-FI | LOCAL OTA` 明确说明它同时是设置与维护入口。按住 `KEY`
3 秒会开启最多 5 分钟的临时 WPA2 热点，屏幕显示标准 Wi-Fi 二维码、随机密码和
`192.168.4.1`：

![设置门户等待页](assets/settings-portal.svg)

手机页面可以修改 `NORMAL / SAVING`、UTC 偏移、温度单位、回放音量和更新通道，也可使用
手机时间校准 RTC、恢复偏好默认值、清除 Wi-Fi 或上传本项目的 OTA 镜像。Beta 更新默认
关闭，只有能使用本地 OTA 或 USB 恢复设备的开发者主动确认后才加入测试通道；关闭后
立即恢复检查稳定版，但不会自动降级已安装固件。保存偏好、恢复默认值和
清除 Wi-Fi 后设备会安全重启；清除 Wi-Fi 不删除其他偏好。等待连接或普通配置时可短按
`BOOT` 关闭门户，开始接收固件后按键不会中断 Flash 写入。本地 OTA 不依赖互联网，完整
步骤见[固件安装与更新](firmware-update.md)。

“在线更新”显示 `NOT CHECKED`、`CHECKING`、`UP TO DATE`、`UPDATE AVAILABLE` 或
`FAILED`。按住 `KEY` 2 秒检查；已有可用版本时，同样按住 2 秒进入 `REVIEW` 确认页，核对
目标版本后再按住 `KEY` 3 秒才开始安装。`NORMAL` 的自动联网只检查，不会弹出页面或静默
安装；`SAVING` 不自动检查。测试通道时第二行标为 `BETA LATEST`。检查、连接和确认阶段
可按 `BOOT` 取消，开始下载并写入 Flash 后按键不得中断。

其他页面长按 `KEY`，以及任何页面长按 `BOOT`，都不会执行隐藏动作；松开也不会被误判为
短按。

## 异常状态

- RTC 无效时首屏按当前模式使用 `--:--:--` 或 `--:--`，并显示日期占位符；温湿度、
  电量、系统中心和音频功能仍可使用，自动连接、NTP 失败和后台重试不显示全屏错误；
- 仅首次配置或用户在设置门户清除网络配置后显示配网二维码；显示 60 秒后恢复首屏，
  临时热点最多继续开放 5 分钟，也可按屏幕提示的 `BOOT: OFFLINE` 立即回到首屏；
- microSD 未插入、不是 FAT32、目录不存在或没有有效图片时，不显示启动错误或空白图片
  页；`BOOT` 保持在首屏与月历之间切换，RTC、传感器和系统中心不受影响；
- 温湿度不可用时在原位置显示 `--`；电池不可用时保留空图标并显示 `--%`；
- 系统页使用 `NOT FOUND`、`READ ERROR`、`NOT CONFIGURED` 等短状态，详细错误码只写入
  USB 日志。
