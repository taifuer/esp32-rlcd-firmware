# 界面与按键

固件把屏幕内容分为“日常功能”和“系统中心”两条路径。日常页面只保留高频信息；版本、
诊断和维护操作集中到系统中心，避免两个实体键在不同页面承担难以预测的含义。完整设计
原则见[产品界面与交互设计规范](design-guidelines.md)。

```text
日常功能（BOOT）
  首屏 <-> 月历

系统中心（KEY）
  设备健康 -> 网络与时间 -> Wi-Fi 维护 -> 关于与更新 -> 循环
```

## 实体按键

| 按键 | 日常页面 | 系统中心 |
| --- | --- | --- |
| 短按 `BOOT` | 首屏与月历互相切换 | 返回首屏 |
| 短按 `KEY` | 进入“设备健康” | 切换到下一系统页 |
| 长按 `BOOT` | 无运行时操作 | 无运行时操作 |
| 长按 `KEY` | 无操作 | 仅执行当前页面明确提示的操作 |
| `PWR` | 短按开机，长按关机 | 同左 |

月历和所有系统页无操作 30 秒后返回首屏。长按中的按键、校时任务和 Wi-Fi 重置倒计时会
暂停超时。

关机后“按住 `BOOT`，再短按 `PWR`”仍用于进入 ESP32-S3 ROM 下载模式。此时应用固件
没有运行，屏幕不会绘制烧录进度；它与正常运行时的 `BOOT` 页面切换是两种不同场景。

## 首屏

![首屏效果图](assets/home-screen.svg)

400 × 300 首屏采用黑底白字三段式布局：

- 顶部显示公历日期、无“农历”前缀的农历月日、星期，以及 Wi-Fi 与电池状态组；四组
  按实际宽度分配相等间距，状态组使用固定占位，避免内容跳动；
- 中部以同一种 78 像素数字字体等大显示 `HH:MM:SS`，字形视觉中心位于整屏中央；
- 底部只显示温度、心形分隔和湿度。温湿度使用 20 像素字体，分别以左右半屏为中心；
- 固件版本、传感器诊断、原始电压和网络错误码不进入首屏。

完整 Wi-Fi 图标表示本次启动已成功完成网络校时，不表示无线射频持续开启；下半层图标
表示正在连接或校时，带斜杠表示未配置或最近连接失败。蓝牙尚未启用，因此不显示蓝牙
图标。

农历在设备上离线换算，覆盖 2000—2099 年并支持闰月。温湿度来自板载 SHTC3，代表设备
附近环境，不是联网天气。电池百分比由 GPIO4 采样电压估算，受充电、负载和电芯老化
影响，仅作为近似值。

## 月历

![月历页效果图](assets/calendar-screen.svg)

月历显示 RTC 当前月份，以星期一为每周首日，并用实心圆反色突出今天。顶部显示当月、
当天农历、星期和当前时分。当前版本不提供历史月份翻阅，避免两个按键承担额外模式。

## 系统中心

四个系统页共用标题、`1/4`—`4/4` 位置、内容网格和底部按键提示，但每页只负责一类
问题：

| 页面 | 内容 | 当前页长按操作 |
| --- | --- | --- |
| 设备健康 | RTC、SHTC3、电池和 PSRAM | 无 |
| 网络与时间 | Wi-Fi 状态、RTC、最近校时和 24 小时自动周期 | 按住 `KEY` 2 秒立即校时 |
| Wi-Fi 维护 | 是否已保存网络配置及重配网影响 | 按住 `KEY` 5 秒清除配置并重启 |
| 关于与更新 | 固件、ESP-IDF、USB 烧录步骤和最新 Release 二维码 | 无 |

| 设备健康 | 网络与时间 |
| :---: | :---: |
| ![设备健康页效果图](assets/device-health.svg) | ![网络与时间页效果图](assets/network-time.svg) |
| Wi-Fi 维护 | 关于与更新 |
| ![Wi-Fi 维护页效果图](assets/wifi-maintenance.svg) | ![关于与更新页效果图](assets/about-update.svg) |

“网络与时间”发起校时后会显示启动 Wi-Fi、连接和等待 NTP；写入并回读 RTC 成功后显示
结果，再返回该页面。未保存 Wi-Fi 或网络任务忙碌时只提示不可用，不修改配置。

“Wi-Fi 维护”从按住 `KEY` 1 秒开始显示剩余时间，满 5 秒才清除本项目的网络凭据并重启
配网；提前松开立即取消。其他页面长按 `KEY`、以及任何页面长按 `BOOT` 都不会执行隐藏
动作，松开也不会被误判为短按。

## 异常状态

- RTC 无效时优先显示配网、连接或校时状态；回到首屏时使用 `--:--:--`，不在大时间下方
  叠加文字；
- 温湿度不可用时在原位置显示 `--`；电池不可用时保留空图标并显示 `--%`；
- 系统页使用 `NOT FOUND`、`READ ERROR`、`NOT CONFIGURED` 等短状态，详细错误码只写入
  USB 日志。

## 数据与设计参考

- 农历月界以[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)
  为校验依据；
- 电池采样电路与实体按键依据[微雪 ESP32-S3-RLCD-4.2 文档](https://docs.waveshare.net/ESP32-S3-RLCD-4.2/)；
- 页面层级、浅导航和实体按键语义参考 Apple 与 Garmin 的官方指南，具体链接集中在
  [设计规范](design-guidelines.md#参考原则)。
