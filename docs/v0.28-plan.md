# v0.28.0 日常使用体验

2026-09-14 用户确认实施。本版先发布 Beta 候选，验收后再发布正式版；不改变 CPU、
Wi-Fi 省电策略、页面停留规则、Flash 分区或语音模型。

## 范围与安全边界

- 已连接家庭 Wi-Fi 时，设备主动开启临时局域网门户，扫码授权访问；不常驻开放。
  无可用连接、恢复模式或用户主动切换时，使用原 WPA2 随机密码热点。
- 局域网 HTTP 不提供 Wi-Fi 密码、API Key 编辑和本地 OTA；这些敏感维护操作继续使用
  设备热点。局域网可管理普通偏好、RTC、图片与歌曲。所有数据接口均需会话授权，
  授权材料不写日志、不进入 URL 查询参数、不保存在浏览器持久存储。
- 浏览设置或歌单不停止音乐；写卡和固件事务仍取得独占资源并安全停止音乐。
- 普通门户按用户活动计算 5 分钟闲置时间，另设绝对会话与单事务上限；状态轮询不能续期。
  歌曲支持多选、顺序上传，每首独立校验和提交，失败停止队列，不覆盖同名文件。
- 音乐页突出两行歌名，缩小播放状态；播放音量编辑可试听，取消、超时和抢占恢复最新
  已保存音量，只有保存写 NVS。
- 闹钟音量与媒体音量分开，门户提供设置和短试听；迁移沿用原音量，不突然变响。
  设备仍只提供闹钟开关，不增加调时或音量菜单。

## 升级兼容

偏好记录升级为 schema v8，写入新的 `cfg8_a` / `cfg8_b` 双槽，不覆盖旧记录；迁移保留
时区、温标、媒体音量、闹钟规则、省电偏好和更新通道，闹钟音量继承媒体音量（含静音）。
Wi-Fi、天气、AI 凭据使用各自独立存储，不修改其布局。不更改 Flash 分区或语音模型，
已有 v0.7.0+ 完整安装可以通过 OTA 更新应用。

回退到仅支持 schema v7 的旧固件时，它会使用安全默认偏好并保护新记录，不等于新偏好
丢失；重新升级可恢复 v8 保存值。Wi-Fi 与 API 凭据不随偏好回退清除。

局域网令牌每次开启更新，浏览器只在内存保留，刷新后重新授权。访问码错误最多尝试
8 次，间隔至少 1 秒；超过后仍可扫码，或重新开启门户。HTTP 不是加密连接，仅限可信
家庭局域网，不做路由器端口映射，不把访问码或二维码发到公共平台。

## 实机验收顺序

1. Beta 在线安装后核对版本与原设置；首屏、天气、图片、AI 与离线语音均可正常使用。
2. 家庭 Wi-Fi 已连接时打开网页设置，手机保持同一网络扫码；关闭后重新开启，旧访问码
   失效。直接输入 IP 时需访问码；未授权不能读取设置、歌曲和图片。
3. 局域网中试普通设置和歌曲管理；API Key、Wi-Fi 编辑及本地 OTA 禁用。
   短按设备 `KEY` 切回热点，凭据编辑与本地 OTA 仍可用；普通关闭后恢复家庭连接。
4. 播放中打开门户和刷新歌单，声音不中断；选择多首歌曲，上传顺序、数量、进度正确。
   中断第二首上传，重新打开后第一首保留，半文件不出现，不影响原有文件。
5. 音乐页显示两行长歌名。按住 `BOOT` 2 秒调音量，试低档位、静音、取消、保存和
   30 秒无操作；取消或超时应恢复已保存音量，保存后重启仍保留。
6. 媒体音量为 0，独立闹钟音量设为适中值并保存，到点应有声。闹钟音量为 0 则只显示
   提醒。试听不保存，真实闹钟可抢占试听；按键停止后不能迟到再次响起。
7. 关机取卡后开机，无卡提示不影响时钟与设置；断开路由器或启用省电后门户仍走热点。
   不热插拔，不用正在写入的卡做断电试验。空闲 5 分钟关闭，有操作可续期但不超过
   30 分钟；恢复门户仍保留精简功能和本地 OTA。
