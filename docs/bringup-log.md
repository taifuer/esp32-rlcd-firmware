### 复位观察

- 普通 USB `hard-reset` 曾让芯片继续停在 Bootloader。
- Watchdog reset 可以启动应用，但 Windows 端口重枚举可能让 esptool 返回串口异常。
- 因此标准流程固定为：烧录后物理关机，再在不按 BOOT 的情况下正常开机。
