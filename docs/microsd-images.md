# microSD 图片准备

本文说明 v0.12.0 及后续版本的 microSD 目录、图片格式、转换工具和设备交互。

## 存储卡

v0.12.0 的实机验收使用 16 GB、FAT32 格式的 microSD，设备识别容量为
14,910 MiB。固件通过 ESP-IDF 原生 1-bit SDMMC 和 FatFs 读取存储卡，不把联网、
NTP 或其他服务作为启用条件。请使用 FAT32；当前版本不支持 exFAT。

固件对 microSD 的应用层访问始终为只读：

- 不自动格式化存储卡；
- 不创建或修复目录和文件系统；
- 不改名、覆写或删除图片；
- 不在卡上保存设置、日志、温湿度历史或音频测试数据。

插卡、拔卡或更换存储卡前必须使设备物理关机。首版不支持热插拔；即使运行中
插入了卡，也要关机后重新开机才会扫描图片。

## 目录和文件选择

在存储卡根目录创建以下固定路径：

```text
/rlcd/images/
```

图片文件名最多 63 个字节，只能使用 ASCII 英文字母、数字、连字号 `-`、下划线 `_`
和句点 `.`，且不能以句点开头。扩展名为 `.pbm` 或 `.bmp`，不区分大小写；为避免不同
电脑的大小写差异，仍建议全部使用小写，例如：

```text
/rlcd/images/00-main.pbm
/rlcd/images/10-backup.bmp
```

目录中最多允许 32 个符合上述文件名和扩展名的候选。超出上限时固件不猜测哪些文件
应被忽略，而是将本次扫描视为无可用图片。候选先按不区分大小写的 ASCII 文件名顺序
排列，同名折叠时再以原始大小写稳定排序，然后依次完整校验；
损坏、截断或格式不支持的文件被跳过。图片页显示排序后第一张成功解码的图片，
不把其余文件扩展成更长的按键页面环。

如果需要更换屏幕图片，在电脑上调整排序最前的有效文件，安全弹出存储卡，再按照
关机插拔规则重新开机。

## 图片格式

所有图片都必须是 400 × 300 像素，且每个像素只有纯黑或纯白两种状态；单个文件不得
超过 16,384 字节。固件不在设备上缩放、裁切、灰度量化或抖动图片。

### PBM P4（首选）

推荐使用 Netpbm 二进制 PBM `P4`：

- 头部必须声明 `P4` 和 `400 300`；
- 像素负载必须完整，不得截断或附加第二张图像；
- 使用 `.pbm` 扩展名。

PBM P4 结构简单，没有调色板或压缩变体，是默认转换输出。

### 1-bit BMP（限定子集）

BMP 只作为窄兼容输入，必须同时满足：

- 400 × 300 像素、1 bit per pixel；
- 40 字节 `BITMAPINFOHEADER`，可使用标准自下而上或自上而下行顺序；
- 未压缩的 `BI_RGB` 像素数据；
- 调色板只包含可判定的纯黑和纯白；
- 像素偏移、行对齐和文件长度都与头部一致；
- 使用 `.bmp` 扩展名。

带颜色、灰度、RLE 压缩、位域或其他 BMP 变体不在首版支持范围内。电脑端检查或转换工具
应与固件使用同一组边界，不以“电脑能打开”代替固件校验。

## 底部保留区

文件画布虽然是 400 × 300，但固件会覆盖底部 `y=250`—`299` 的 50 像素：

```text
y=0   +----------------------------------------+
      |                                        |
      |       主要图像内容 400 × 250          |
      |                                        |
y=250 +----------------------------------------+
      |       BOOT: PAGE | KEY: SYSTEM         |
y=300 +----------------------------------------+
```

分隔线位于 `y=250`，底部操作区使用不透明黑底和白字，确保任何图片上都能看清按键语义。
准备图片时应将主体、人脸和文字完整放在顶部 400 × 250 区域，底部像素不视为可见内容。

## 电脑端检查与转换

仓库中的 `tools/rlcd-image.py` 使用与固件一致的 PBM/BMP 边界检查已准备好的文件：

```bash
python3 tools/rlcd-image.py check 00-main.pbm
```

检查成功会输出格式、尺寸、文件大小和 SHA-256。它只读输入文件，不会修复或覆盖文件。

将 JPEG、PNG 等常见图片转为默认 PBM P4 输出：

```bash
python3 tools/rlcd-image.py convert input.jpg 00-main.pbm
```

转换需要 Python Pillow；未安装时工具会给出明确提示。工具保持源图比例，将它缩放并居中到
顶部 400 × 250 可见区，底部 50 像素填充为黑色，再对整幅 400 × 300 画布二值化。
默认阈值为 128 且不抖动；可按图片选择：

```bash
python3 tools/rlcd-image.py convert --threshold 150 input.jpg 00-main.pbm
python3 tools/rlcd-image.py convert --dither input.jpg 00-main.pbm
```

默认不覆盖已有输出；只有确认目标可被替换时才添加 `--force`。转换完成后工具会重新
读取并校验输出，仍可再手动执行一次 `check` 后复制到 `/rlcd/images/`。

## 设备交互

有效图片成功读取后，日常页面环为：

```text
首屏 -> 月历 -> 图片 -> 首屏
```

- 图片页短按 `BOOT` 回到首屏；
- 图片页短按 `KEY` 进入系统中心的“状态”页；
- 长按 `BOOT` 或 `KEY` 不执行隐藏动作，松开后也不误判为短按；
- 图片页无操作 30 秒后回到首屏；
- 页面不轮播、不动画，也不按秒重新读取存储卡。

无卡、挂载失败、目录不存在或 32 个候选中没有有效图片时，图片页完全隐藏；
`BOOT` 仍在首屏与月历之间切换。固件不用全屏错误打断 RTC 时钟、日历、传感器或其他
本地功能，详细失败原因只保留在 USB 诊断日志。

## 故障排查

| 现象 | 检查 |
| --- | --- |
| `BOOT` 只在首屏和月历之间切换 | 确认固件为 v0.12.0 或更新版本；再检查 FAT32、固定目录、不超过 32 个候选和图片格式 |
| 排在最前的文件没有显示 | 该文件校验失败时会继续查找下一张有效图片；用电脑端工具检查它 |
| 图片底部被黑色操作区覆盖 | 这是固件保留的固定区域；将主要内容移到顶部 400 × 250 安全区 |
| 运行中插卡后页面未出现 | 物理关机，确认存储卡已稳固插入，再正常开机 |
| 卡内容没有被固件自动修复 | 固件按设计只读且不格式化；在电脑上备份后检查或重新准备存储卡 |

取出存储卡前始终先关机。如果卡上有其他重要文件，仍应在电脑上保留独立备份；应用层
只读设计不代替存储卡自身的可靠性和备份。
