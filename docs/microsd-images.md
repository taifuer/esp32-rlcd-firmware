# microSD 图片

本文说明当前固件的 microSD 目录、图片格式、导入、网页管理和设备端安全删除。
安装行为以[发布固件安装指南](user-install.md)为准。

## 存储卡

v0.12.0 的实机验收使用 16 GB、FAT32 格式的 microSD，设备识别容量为
14,910 MiB。固件通过 ESP-IDF 原生 1-bit SDMMC 和 FatFs 读取存储卡，不把联网、
NTP 或其他服务作为启用条件。请使用 FAT32；当前版本不支持 exFAT。

存储卡完全可选。无卡、挂载失败或没有有效图片时，固件不显示启动错误，
不加入图片页；RTC 时钟、日历、传感器、离线语音、网络校时和固件更新均不受影响。

普通展示保持只读；只有用户在设置门户中确认的图片导入，或在设备图片页、设置门户中
明确确认的单张删除，才会临时以写方式挂载卡：

- 不自动格式化存储卡；
- 不修复文件系统，不覆写或改名已有图片，也不自动清理或批量删除；
- 明确导入时只按需创建 `/rlcd/` 和 `/rlcd/images/`，新图片使用内容摘要派生的
  文件名，相同内容去重；
- 先写入有界的临时文件，完整校验格式和大小并计算 SHA-256 后才完成导入；
  演示图还必须与服务器清单中的摘要匹配，中断或失败会清理临时文件；
- 单张删除只接受当前运行时目录中已经校验的图片；设备端使用“长按进入确认、松开后
  再短按删除”，网页端使用二次确认，删除失败时都保持文件、当前图片和运行时目录不变；
- 不在卡上保存设置、日志、温湿度历史或音频测试数据。

插卡、拔卡或更换存储卡前必须使设备物理关机。当前不支持热插拔；运行中
插入或更换的卡要到重新开机才扫描。设置门户中的受控导入，以及设备端或设置门户中的
受控删除是例外：成功后会安全更新现有运行时目录，不需要重启，也不重新扫描其他文件。

## 目录和文件选择

在存储卡根目录创建以下固定路径：

```text
/rlcd/images/
```

图片文件名最多 63 个字节，只能使用 ASCII 英文字母、数字、连字号 `-`、下划线 `_`
和句点 `.`，且不能以句点开头。扩展名为 `.pbm` 或 `.bmp`，不区分大小写；为避免不同
电脑的大小写差异，仍建议全部使用小写，例如：

```text
/rlcd/images/00-main.pbm
/rlcd/images/10-backup.bmp
```

候选先按不区分大小写的 ASCII 文件名顺序排列，同名折叠时再以原始大小写稳定
排序；损坏、截断或格式不支持的文件被跳过。

固件会完整校验候选，并把排序最前的最多 32 张有效图片缓存到 PSRAM。页面始终只显示
当前选中的一张，不把每个文件扩展成更长的按键页面环；缓存已达上限或扫描结果被截断时
不再导入新图片。

## 图片格式

所有图片都必须是 400 × 300 像素，且每个像素只有纯黑或纯白两种状态；单个文件不得
超过 16,384 字节。固件不在设备上缩放、裁切、灰度量化或抖动图片。

### PBM P4（首选）

推荐使用 Netpbm 二进制 PBM `P4`：

- 头部必须声明 `P4` 和 `400 300`；
- 像素负载必须完整，不得截断或附加第二张图像；
- 使用 `.pbm` 扩展名。

PBM P4 结构简单，没有调色板或压缩变体，是默认转换输出。

### 1-bit BMP（限定子集）

BMP 只作为窄兼容输入，必须同时满足：

- 400 × 300 像素、1 bit per pixel；
- 40 字节 `BITMAPINFOHEADER`，可使用标准自下而上或自上而下行顺序；
- 未压缩的 `BI_RGB` 像素数据；
- 调色板只包含可判定的纯黑和纯白；
- 像素偏移、行对齐和文件长度都与头部一致；
- 使用 `.bmp` 扩展名。

带颜色、灰度、RLE 压缩、位域或其他 BMP 变体不在首版支持范围内。电脑端检查或转换工具
应与固件使用同一组边界，不以“电脑能打开”代替固件校验。

## 底部保留区

文件画布虽然是 400 × 300，但固件会覆盖底部 `y=250`—`299` 的 50 像素：

```text
y=0   +------------------------------------------------------+
      |                                                      |
      |              主要图像内容 400 × 250                 |
      |                                                      |
y=250 +------------------------------------------------------+
      | BOOT: HOME | KEY: NEXT IMAGE | 2/6                  |
      | HOLD KEY 2s: DELETE IMAGE                            |
y=300 +------------------------------------------------------+
```

分隔线位于 `y=250`，底部操作区使用不透明黑底和白字，确保任何图片上都能看清按键语义。
多图时提示 `KEY: NEXT IMAGE` 和当前位置，单图时提示 `KEY: STATUS`，两种情况都明确提示
`BOOT: HOME` 与 `HOLD KEY 2s: DELETE IMAGE`。准备图片时应将主体、人脸和文字完整放在
顶部 400 × 250 区域，底部像素不视为可见内容。

## 电脑端检查与转换

仓库中的 `tools/rlcd-image.py` 使用与固件一致的 PBM/BMP 边界检查已准备好的文件：

```bash
python3 tools/rlcd-image.py check 00-main.pbm
```

检查成功会输出格式、尺寸、文件大小和 SHA-256。它只读输入文件，不会修复或覆盖文件。

将 JPEG、PNG 等常见图片转为默认 PBM P4 输出：

```bash
python3 tools/rlcd-image.py convert input.jpg 00-main.pbm
```

转换需要 Python Pillow；未安装时工具会给出明确提示。工具保持源图比例，将它缩放并居中到
顶部 400 × 250 可见区，底部 50 像素填充为黑色，再对整幅 400 × 300 画布二值化。
默认阈值为 128 且不抖动；可按图片选择：

```bash
python3 tools/rlcd-image.py convert --threshold 150 input.jpg 00-main.pbm
python3 tools/rlcd-image.py convert --dither input.jpg 00-main.pbm
```

默认不覆盖已有输出；只有确认目标可被替换时才添加 `--force`。转换完成后工具会重新
读取并校验输出，仍可再手动执行一次 `check` 后复制到 `/rlcd/images/`。

## 设置门户图片管理

无卡时，设置门户只将图片导入和演示图入口显示为不可用，不弹出错误、不阻塞其他设置。

### 手机本地转换与导入

1. 按[网页设置入口](device-settings.md#网页设置)打开门户，连接屏幕所示的临时热点。
2. 选择 JPEG 或 PNG。源文件最大 32 MiB、解码后最多 4,000 万像素；浏览器在手机本地
   保持比例缩放到顶部 400 × 250 可见区，底部 50 像素留黑。
3. 调整二值化阈值，按需启用 Floyd–Steinberg 抖动，先检查最终 400 × 300 黑白预览。
4. 只有在“写入 microSD”的确认对话中继续，浏览器才会将生成的 PBM P4 发给设备。
   原始 JPEG/PNG 不会发给设备或上传到互联网。
5. 固件完成写入、校验和去重后立即选择这张图片并更新运行时缓存，设备和设置热点
   都不重启。

### 公共演示图

“安装演示图集”会在二次确认后关闭临时设置热点，设备使用已保存的 Wi-Fi 连接
`mcu.taifua.com`，按固定 HTTPS 清单下载 6 张公共 PBM 演示图。设备屏幕显示连接、
清单、下载、校验和结果；每张图都经过大小与 SHA-256 校验，完成后直接加入运行时
缓存，设备不重启。

该操作需要设备已保存可用的 Wi-Fi；不会在启动或普通运行时自动下载。无卡、
无已保存 Wi-Fi 或图片容量已达上限时不开始安装；卡不可写或网络中断时安全失败，
不覆盖原有图片。

### 图片选择

固件不按小时、日期或其他周期自动更换图片。多图时，在图片页短按 `KEY` 可以立即查看
下一张；手机导入、完整安装的演示图集首图、实体键切换和设置门户“设为当前”都会更新
首选图片。用户最后选择哪张，设备就持续显示哪张，并在重新启动后恢复同一选择。

### 设置门户浏览与删除

设置门户使用单张预览管理当前运行时目录，可前后浏览、将某张图片设为当前，或删除单张
图片。删除按钮使用次级危险样式，并在真正写卡前再次确认；固件不提供“一键清空”或批量
删除。删除当前图片后会选择相邻图片；删除最后一张后图片页立即从日常页面环中隐藏。
上述操作都不重启设备，设置热点和网页保持可用。

### 设备端单张删除

在图片页普通短按 `KEY` 仍执行切图或进入系统中心；持续按住 1 秒会显示长按提示，此后
未满 2 秒松开只取消长按。按满 2 秒只进入当前图片的删除确认，不会直接写卡；进入确认页后
必须先完整松开 `KEY`，再短按 `KEY` 才会删除，短按 `BOOT` 或 10 秒无操作都会取消。
确认页继续显示待删除图片，原长按尚未松开时显示 `RELEASE KEY | BOOT: CANCEL`，松开后
改为 `BOOT: CANCEL | KEY: DELETE`。首版不提供批量删除。

确认后由异步任务执行写卡，普通页面导航暂时停用。成功或失败结果保持至少 2 秒；成功后
显示下一张，删除末张后回到首张，删除最后一张时图片页从日常页面环中隐藏。挂载、查找
或移除文件失败时，
设备保留原文件、当前图片和运行时目录并提示稍后重试；文件已经成功移除后，运行时目录
同步更新，卸载阶段的附加错误只记录到 USB 日志。整个过程无需重启。

## 设备交互

有效图片成功读取后，日常页面环为：

```text
首屏 -> 月历 -> 图片 -> 首屏
```

- 图片页短按 `BOOT` 回到首屏；
- 多图时，图片页短按 `KEY` 切换到下一张，底部同时显示当前位置；单图时短按 `KEY`
  仍进入系统中心的“状态”页；
- 图片页按住 `KEY` 2 秒进入当前图片的删除确认；确认页必须先松开，再短按 `KEY` 删除，
  短按 `BOOT` 或等待 10 秒取消；长按 `BOOT` 仍不执行隐藏动作；
- v0.26.0 起图片页一直停留，由用户手动切换；v0.25.0 及更早版本仍在无操作 30 秒后回到首屏；
- 固件记住用户选择，不自动轮播、不动画，也不按秒重新读取存储卡。

无卡、挂载失败、目录不存在或没有有效图片时，图片页完全隐藏；
`BOOT` 仍在首屏与月历之间切换。固件不用全屏错误打断 RTC 时钟、日历、传感器或其他
本地功能，详细失败原因只保留在 USB 诊断日志。无卡不是需要修复的错误。

## 故障排查

| 现象 | 检查 |
| --- | --- |
| `BOOT` 只在首屏和月历之间切换 | 确认固件为 v0.12.0 或更新版本；再检查 FAT32、固定目录、候选数量和图片格式 |
| 某个文件没有显示 | 文件校验失败时会继续查找其他有效图片；用电脑端工具检查它 |
| 图片底部被黑色操作区覆盖 | 这是固件保留的固定区域；将主要内容移到顶部 400 × 250 安全区 |
| 运行中插卡后页面未出现 | 物理关机，确认存储卡已稳固插入，再正常开机 |
| 设置门户显示图片导入不可用 | 确认已关机插入 FAT32 卡，且图片缓存未达 32 张 |
| 删除图片失败 | 确认存储卡仍然稳固且可写；设备端和设置门户的失败都不会移除运行时图片，可稍后重试或关机后用电脑整理 |
| 演示图集不能安装 | 确认 microSD 可用、设备已保存正确 Wi-Fi，并查看设备屏幕上的下载结果 |
| 导入后图片页没有更新 | 重新进入图片页；若仍未出现，检查是否已达到 32 张上限并查看 USB 日志 |
| 卡内容没有被固件自动修复 | 固件按设计不修复或格式化文件系统；在电脑上备份后检查或重新准备存储卡 |

取出存储卡前始终先关机。如果卡上有其他重要文件，仍应在电脑上保留独立备份；
受控导入事务不代替存储卡自身的可靠性和备份。
