# 开发计划

本文记录已经确定、但尚未进入正式版本的功能方向。每一项仍需经过主机测试、完整构建和
实机验收，完成后再移入版本变更记录。

## v0.12.0：microSD 图片展示

microSD 支持与一个完整的用户功能同时交付，不单独发布只能识别或挂载存储卡的版本。

- [ ] 使用 ESP-IDF 原生 1-bit SDMMC 和 FatFs 读取 FAT32 存储卡；
- [ ] 增加日常图片页，从固定目录读取尺寸和格式受限的黑白 BMP/PBM；
- [ ] 首版只读挂载、不自动格式化，并要求关机插拔存储卡；
- [ ] 无卡、格式不支持、文件损坏或挂载失败时，时钟和其他本地功能仍正常启动；
- [ ] 提供图片检查或转换工具，并覆盖目录扫描、格式校验和错误恢复测试。

温湿度历史记录需要进一步设计断电恢复、文件轮转和安全写入，放在图片展示稳定后评估。
SD 卡不用于保存音频诊断的临时语音。

实现以上版本时，应同步更新产品设计规范、界面与按键说明、SVG 效果图、主机测试和实机
验收记录。
