# 设备设置

以下对应 **v0.29.0**。
设置页电源标签与状态上下居中，操作提示与小字字重已调整；按键和省电规则不变。

## 打开网页设置

1. 按屏幕提示用 `KEY` 切到 `SETTINGS`。
2. 按住 `KEY` **2 秒**，直接打开网页设置，不经过二级菜单。
3. 手机与设备连接同一家庭 Wi-Fi 时，扫描屏幕二维码即可进入。也可在浏览器打开屏幕
   显示的地址，再输入 8 位 `ACCESS CODE`。

![设置页示意](assets/settings.svg)

没有可用家庭连接或处于省电模式时，使用设备热点：扫码连接，未自动打开网页时访问
`http://192.168.4.1`。热点不需要互联网，退出后按省电设置恢复家庭网络。

局域网连接使用 HTTP，仅限可信家庭网络，可修改普通偏好、校时和管理媒体。
Wi-Fi 密码、天气和 AI 配置、本地 OTA 继续在设备热点中操作；在设备短按 `KEY`，
或点击网页的“切换到设备热点”。不要做路由器端口映射或公开访问码、二维码。

每次开启都会更新授权；刷新网页后需重新扫码或输入访问码。浏览网页、切换分区与查看
歌单不会停止音乐；上传、删除或试听闹钟时会停止音乐，不会在结束后自动续播。

## 网页分区

| 分区 | 内容 |
| --- | --- |
| 常用 | 时区、温度单位、播放音量、手机时间校准；闹钟按需展开 |
| 联网 | 当前或已保存的 Wi-Fi；天气、市场看板与 AI 配置按需展开 |
| 媒体 | 歌曲列表、上传、播放和删除；图片管理按需展开 |
| 维护 | Beta 更新开关、本地 OTA；恢复默认值单独展开并确认 |

常用、闹钟与更新设置分别保存。切换分区不刷新表单，保存一项不清除其他未保存输入；
保存失败保留草稿。普通设置保存后立即生效，不重启。无 SD 卡时媒体操作不可用，
其他功能不受影响。图片与音乐的详细操作见 [图片管理](microsd-images.md)和
[音乐播放](music-player.md)。

闹钟默认关闭，规则为工作日 07:30；开启前请确认 RTC 时间正确。闹钟使用独立音量，
0% 时只有屏幕提醒，媒体静音不影响它。升级沿用原音量，不突然变响。
“试听闹钟”播放最多 3 秒，不保存设置；调整后点击“保存闹钟”。

普通门户在闲置 5 分钟后关闭；输入和点击会续期，自动轮询不会。一次最多 30 分钟，
已开始的上传有独立的 10 分钟时限，不因跨过闲置期而中断。短按 `BOOT` 可关闭门户，
写卡或本地 OTA 期间不可中断。

## 设备端保留的操作

- 设置页按住 `BOOT` 2 秒：开关手动提前省电。自动低电保护继续生效，不需要网页。
- 音乐页按住 `BOOT` 2 秒：直接调音量。短按 `KEY` 按 10% 档位循环，长按 2 秒保存，
  短按 `BOOT` 取消；音乐播放中可听到变化，取消或 30 秒无操作恢复已保存音量。
- 闹钟启停、时刻和重复日期统一在网页配置，设备响铃时仍可停止或延后。

日常功能由 `BOOT` 依次切换：时钟、可选天气、可选市场看板、日历、可选图片、可选音乐、对话。
系统页由 `KEY` 切换：设置、在线更新、状态。对话不再属于系统页。

普通页面停在用户选中的位置，不自动回时钟；正常开机仍进入时钟。
图片记住选中的文件，不自动轮播。会话、删除确认和门户仍有各自的时限。

## 市场看板 Beta

“联网”新增[市场看板](market-dashboard.md)：开关、从 15 个预设选择 1–5 个指数、调整顺序。
默认关闭，无需 API Key 或 SD 卡。可在已授权的同 Wi-Fi 网页或设备热点操作，保存不重启，
也不清除其他表单的草稿。
开启后，日常页面环在天气与月历之间加入 `MARKET`；没有启用天气时，位于时钟之后。

## 旧版本与恢复模式

- v0.27.0 与 0.28.0-dev.1：设置页长按 `KEY` 2 秒进入快捷菜单，再选择 `WEB SETTINGS`。
- v0.26.0：进入快捷菜单的长按为 3 秒。
- v0.25.0 及更早：设置页长按 `KEY` 3 秒直接打开网页。
- 启动恢复模式：设置页长按 `KEY` 3 秒打开精简热点门户，仅提供 Wi-Fi 与本地 OTA，
  没有普通设置的闲置截止时间。

门户改版记录见 [v0.28.0 计划](v0.28-plan.md)，市场看板验证见[市场看板](market-dashboard.md)。

[AI 对话配置](cloud-voice.md)。
