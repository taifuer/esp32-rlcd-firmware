# 设备设置

以下说明对应 **v0.27.0 候选**。v0.26.0 的快捷设置入口需长按 3 秒，候选统一为 2 秒。
v0.25.0 及更早版本在“设置”页长按 `KEY` 3 秒直接打开网页设置。

## 快捷设置

短按 `KEY` 切到 `SETTINGS`，按住 `KEY` 2 秒后松开，进入 `QUICK SETTINGS`。
这里仍属于“设置”，不会增加系统页面数量。

| 项目 | 可以调整的内容 |
| --- | --- |
| `VOLUME` | 播放音量，0% 为静音；修改时按 10% 档位循环 |
| `ALARM` | 开启或关闭已有闹钟；同时显示已保存的时刻和重复日期 |
| `WEB SETTINGS` | 打开手机网页，配置 Wi-Fi、API Key、闹钟时间或进行本地 OTA 等 |

菜单中短按 `KEY` 选择下一项；音量按住 2 秒进入编辑，闹钟按住 2 秒直接切换并保存，
网页设置按住 2 秒打开门户。短按 `BOOT` 返回。
编辑时短按 `KEY` 修改，按住 2 秒保存；短按 `BOOT` 取消本项编辑。
修改只有在明确保存后才生效，不需要重启，也不会为普通设置开启热点。

![快捷设置菜单示意](assets/quick-settings.svg)

音量原来不是整十数值时，会先显示原值；第一次修改才进入整十档位。
闹钟的时刻与重复日期仍在网页中设置，默认是关闭的工作日 07:30；启用前请确认 RTC
时间正确。音量为 0% 时闹钟只有屏幕提醒。

保存失败会保留候选值，可再次保存或取消；已经保存但暂不能应用时显示
`SAVED | APPLYING`，后台会重试。编辑中 30 秒无操作会取消草稿，回到快捷菜单；
菜单列表本身不超时。闹钟响起时会取消草稿并关闭菜单，提醒结束后恢复“设置”页。

## 页面停留

切到哪一页，就停在哪一页，不必单独设置。时钟、天气、日历、图片和系统页
都不会因为长时间不按键而自动返回，按屏幕底部提示手动切换或返回即可。

- 正常开机仍进入时钟，不记忆上次页面。
- 天气请求失败仍留在天气页；有缓存时继续显示，并标注更新时间与过期状态。
- 图片页一直显示选中的文件，多图仍可短按 `KEY` 切换，不自动轮播。
- 天气被关闭或最后一张图片被删除后，对应页面不再可用，才回到时钟。
- 对话、热点、删除与安装确认仍保留各自的操作时限，结束后回到所在功能页。

不再提供 `DISPLAY` 选项。升级后忽略 v0.26.0-dev.1 保存的常驻页选择，其余配置保留，
无需恢复出厂设置。`BOOT: HOME` 与语音“主界面”仍表示时钟；microSD 插拔仍需先关机。

## 网页设置

- **v0.27.0 候选**：`SETTINGS` 按住 `KEY` 2 秒（v0.26.0 为 3 秒）→ 松开 → 短按 `KEY` 选中
  `WEB SETTINGS` → 按住 `KEY` 2 秒。
- **v0.25.0 及更早版本**：`SETTINGS` 按住 `KEY` 3 秒，直接打开。
- **启动恢复模式**：保持原操作，`SETTINGS` 按住 `KEY` 3 秒打开精简恢复门户。

看到二维码后连接屏幕显示的热点，未自动打开网页时访问 `http://192.168.4.1`。
普通设置热点最长开放 5 分钟，短按 `BOOT` 可以关闭；本地 OTA 已开始写入时不能中断。
热点开启期间家庭 Wi-Fi 暂停，关闭后按当前电源状态恢复。

天气与 AI 配置按需展开，各区独立保存；保存一项不会清掉其他区域尚未保存的输入。
门户底部提供项目站点链接，年份取当前手机时间，不加载外部页面资源。

音乐页也可按住 `BOOT` 2 秒直接调音量，保存或取消后返回音乐页；编辑中 30 秒无操作
丢弃草稿并返回音乐页，不进入系统菜单。见 [microSD 音乐播放](music-player.md)。
