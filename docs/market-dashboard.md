# 市场看板

v0.29.0 提供的可选 Beta 功能，默认关闭。无需 API Key 或 microSD。

## 打开与使用

1. 在设备 `SETTINGS` 按住 KEY 2 秒，按屏幕提示打开网页设置。
2. 进入“联网 → 市场看板”，开启功能，从预设中选择 1–5 个指数，并调整显示顺序。
3. 保存并退出网页，在设备短按 BOOT 切到 `MARKET`。它位于可选天气之后、月历之前。

支持已授权的同 Wi-Fi 网页和设备热点；设置保存后生效，不重启、不自动切走当前页面。
默认勾选上证指数、沪深300、恒生指数、纳斯达克综合和标普500，只有开启后才显示看板。

页面展示名称、点位、涨跌幅，以及每个指数自己的报价日期和时间。数字保留两位小数，
上涨用 `+`、下跌用 `-`，零变动显示 `0.00%`。少于五项时不拉大行高。

- 短按 BOOT：下一页（月历）。
- 短按 KEY：设置页。
- 按住 KEY 2 秒：手动刷新一次；请求期间仍可离开本页。

![市场看板示意](assets/market-screen.svg)

示意图使用固件同款字库；示例报价不是实时行情。

开发时可用 `./scripts/preview-market.sh` 输出同布局的原生像素 SVG，无需设备或联网。

## 刷新与离线

`NORMAL` 模式停留本页时约每 2 分钟请求一次，离开页面停止周期获取；刚获取过的数据
不会因来回切页而重复请求。网络资源繁忙或获取失败会等待重试，不阻塞按键和时钟。

`SAVING` 不为看板自动联网；长按刷新可临时联网，结束后恢复既有省电策略。是否仍保留
Wi-Fi 连接由整个设备的电源模式决定，不由页面自行改写。

首次无数据显示 `--`；某项获取失败保留这一项的原值、原报价时间，并在时间后标 `*`。
其他成功的项目照常更新。全部失败时在页脚提示，不整屏弹出错误或返回时钟。

顶部时间来自设备 RTC；每行报价时间沿用新浪返回的北京时间（UTC+8），不跟随设备时区
转换。各市场交易时段不同，时间不一定一致；闭市与节假日可能保留之前的交易日期。
没有交易日历时不推断“正在交易”，也不把请求成功等同于获得实时新报价。

只把开关与选择顺序写入 NVS；报价缓存在 RAM，重启后重新获取。不会周期写 Flash 或 SD。

## 数据与预设

设备通过校验证书的 HTTPS 直接访问新浪 `hq.sinajs.cn`，不经过项目服务器。
本版仅请求已选指数；不需要 Key，但不承诺该公开行情接口的可用性、数据延迟或长期稳定性。

| 预设 | 上游代码 |
| --- | --- |
| 上证指数 | `sh000001` |
| 深证成指 | `sz399001` |
| 创业板指 | `sz399006` |
| 沪深300 | `sh000300` |
| 中证500 | `sh000905` |
| 上证50 | `sh000016` |
| 科创50 | `sh000688` |
| 恒生指数 | `hkHSI` |
| 恒生科技 | `hkHSTECH` |
| 纳斯达克综合 | `gb_ixic` |
| 纳斯达克100 | `gb_ndx` |
| 标普500 | `gb_inx` |
| 道琼斯 | `gb_dji` |
| 日经225 | `znb_NKY` |
| 台湾加权 | `znb_TWJQ` |

不支持输入任意股票代码或接口地址。首版不包含个股、K 线、提醒、自动排序或期货替代。

实现参考同作者的 [fund_valuation](https://github.com/taifuer/fund_valuation)：指数预设、
新浪字段解析以及异常数据处理。日经和台湾使用世界指数格式，不能直接套用 A 股解析器。
上游 GB18030 名称不进入屏幕，固件用本地固定中文名称，只解析 ASCII 数字与日期；
不执行返回的 JavaScript。对空响应、缺失字段、非法日期、非有限数值、重复代码和超长内容
做边界检查，不接受倒退的报价时间。

整体使用反馈；下列专项场景没有逐项实测记录，继续保留：

- 开启后能从 BOOT 页面环进入看板；配置保存、选择 1/5 项、排序和重启后保留配置。
- 五行文字清晰，无覆盖；正负号、各市场不同报价日期、页脚与刷新状态可辨认。
- 停留至少 4 分钟能更新；离开后不继续周期请求；快速来回切换不重复拉取。
- 断网时已有行情不消失，按键正常；重启且无网络时显示空值，不无限重启或跳页。
- 省电时不自动刷新；手动刷新结束后恢复离线，闹钟、天气、对话和 OTA 不互抢网络资源。
- 同 Wi-Fi / 热点门户均可管理；其他表单草稿保留；恢复门户不显示市场设置。

### 本地验证（2026-09-16）

- 页面状态测试覆盖全部 16 种可选功能组合；长按取消、执行后松手不误触短按，
  恢复模式不进入看板。应用集成检查确认刷新不跳页，后台工作受页面和省电状态限制。
- 解析器使用有界字段校验，已用当日真实响应分三组解析全部 15 个指数；主机回归覆盖
  空值、非法数字/日期、重复响应、部分缺失、报价倒退、未来时间和 120 秒调度规则。
- 按固件实际请求头检查默认五项，HTTPS 返回未压缩的 GB18030 正文（1,011 字节）。
  使用 `Accept-Encoding: identity`；若上游仍返回压缩内容，则安全拒绝，不尝试误解析。
- 实际服务代码在模拟 RTOS 下验证了请求互斥、离页取消、手动省电刷新、部分失败缓存、
  保存配置后的旧响应丢弃、配置代次竞争和排队刷新后离页的状态恢复；
  NVS 测试覆盖重启加载、相同配置不重复写入、损坏记录回到默认值及保存失败保留原配置。
- HTTP 测试运行实际客户端代码，覆盖分块/截断、16 KiB 上限、内存失败、取消和释放，
  并模拟单次底层调用内的慢速响应。已连接 socket 的接收截止时间使用独立单次定时器，
  只中断接收；等待回调结束后才关闭 HTTP/TLS，防止迟到回调操作已经复用的连接。
  DNS/TLS 建连仍受 SDK 机制约束，不能据此承诺所有取消都在 4 秒内完成。
- 真正的 U8g2 字体解码测试覆盖名称和数字边界、0–5 行布局与 112 种显示状态；
  生成的预览与固件共用排版，像素边界检查和本地浏览器目视检查通过。
- 门户真实内嵌脚本测试覆盖选择上限、排序、保存失败保留草稿、其他分区输入不被清空、
  局域网授权和恢复模式隔离；本机 Chromium 320 / 390 / 768 像素宽度无横向溢出。

上述均为本机验证，不替代目标板上的持续运行、实际功耗和网络异常场景；实机反馈单独记录。

### v0.29.0 正式版

正式版沿用 dev.1 功能源码，不改变分区、离线语音模型或已有配置布局。市场看板继续保持
Beta，默认关闭；从 dev.1 更新会保留已经保存的看板开关、指数和顺序，不必重新设置。
正式 OTA 为 2.21 MB，与 dev.1 等长；差异仅位于版本、构建时间与摘要校验字段。
固件文件、校验值和本版效果图见[v0.29.0 发布说明](../dist/v0.29.0/README.md)，
